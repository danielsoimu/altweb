# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be direct about the code, decent with the people. Technical
disagreement — including blunt, well-argued criticism of this project's design
— is welcome and expected. Harassment, personal attacks, and bad-faith conduct
are not.

Enforcement: report conduct issues to the maintainer via
[GitHub private vulnerability reporting](https://github.com/danielsoimu/altweb/security/advisories/new)
(it is a private channel that reaches only the maintainer) or any contact
listed on the maintainer's GitHub profile. Reports are handled confidentially.
